## Module 12 Assignment

This repository contains my work for Module 12. The assignment involved conducting a business analytics project using Python to analyze sales, customer, and operational data for GreenGrocer, a five-location organic grocery chain across Florida.

##Files Included
-module12-assignment.py

##What I Practiced
In this assignment, I got hands-on experience working through the full analytics process: descriptive, diagnostic, predictive, and prescriptive analysis using a realistic multi-dimensional dataset. I used Pandas to organize, group, and reshape sales, customer, and operational data across stores, departments, time periods, and customer segments. I also built and interpreted a linear regression model using NumPy’s least-squares solver and SciPy’s linregress to predict store sales and forecast department trends.

I practiced creating correlation matrices to figure out which store characteristics had the biggest impact on revenue. On top of that, I applied design principles to different Matplotlib visualizations like heatmaps, grouped bar charts, annotated scatter plots, trend lines with shaded forecast windows, and pie charts so the results would be clear and easy for a non-technical audience to understand.
Finally, I turned all of the technical findings into an executive summary with clear, measurable business recommendations backed by the data.
